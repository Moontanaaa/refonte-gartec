# [Gartec Redesign 2026]

## Objectif
Refonte moderne et professionnelle du site vitrine de **Gartec**, spécialisé dans le contrôle des aires de jeux (Ludomètre FTv3).

## Technologies
- **HTML5** (Structure sémantique & SEO)
- **Vanilla CSS3** (Design premium, Glassmorphism, Responsive)
- **Vanilla JavaScript** (Animations au scroll, Particules, Menu interactif)

## Fonctionnalités
- Design épuré et moderne.
- Animations fluides via `Intersection Observer`.
- Entièrement responsive (Mobile / Tablette / Desktop).
- Formulaire de contact fonctionnel (côté frontend).
- Indicateurs de statistiques animés.
